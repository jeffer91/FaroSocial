# Orquestación 0.23
Máquina de estados persistente: awaiting, referencia proveedor, fase, contador de hasta 60 consultas, intención de publicación antes de la llamada final, confirmación sin ID público cuando el proveedor confirma. Los trabajos previos tienen authorized_at NULL y ninguna ruta concede autorización real. Worker no expuesto, sin cron ni dispatcher operativo. Dispatcher inyectable conecta cuatro adaptadores, valida contexto y consentimiento y requiere repositorio de credenciales con compare-and-swap para renovación. Firma HMAC de URL temporal por trabajo/archivo/proveedor, sin ruta de descarga todavía: requiere verificación adicional de autorización, revocación, metadata, límites y dominio verificado antes de servir. Pendientes repositorio de contexto por trabajo, autorización explícita de producción, entrega HTTP de medios y reconciliación de resultados, controles de revocación y rotación, verificación y pruebas. No se permite reactivar trabajos de ensayo. Las pruebas son simuladas, no envían contenido.
