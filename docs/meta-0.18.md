# Facebook e Instagram 0.18
Meta Graph API v26.0, seleccionada como versión soportada. Facebook Login: páginas administradas con tareas de creación de contenido; Instagram profesional vinculado a página Facebook. No perfiles personales. Scopes separados, estado de uso único, selección explícita de un activo, ventana de 10 minutos, tokens de página cifrados. No se expone token al navegador. Requiere FARO_META_APP_ID, FARO_META_APP_SECRET, FARO_TOKEN_KEY en entorno privado, aplicación Meta y revisión/Advanced Access para permisos, verificación empresarial cuando proceda. Callbacks exactos /oauth/facebook/callback y /oauth/instagram/callback en host de desarrollo. Revisar si el producto Meta exige configuration ID/Facebook Login for Business para la app registrada, expiración granular, permisos efectivos, revocación y eliminación de datos. El token de página no se presume permanente; se debe verificar vigencia antes de publicar. No se implementa publicación ni renovación todavía. Limpieza de selecciones vencidas pendiente. Sin credenciales las conexiones están bloqueadas. No hay pruebas manuales reales.
