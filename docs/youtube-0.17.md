# Conexión YouTube 0.17
OAuth de aplicación web con PKCE, estado aleatorio de uso único, caducidad de diez minutos, vinculación al usuario y marca, y comprobación del canal y scopes. Credenciales cifradas AES-256-GCM con clave externa de 32 bytes y AAD de conexión. El rol editorial no tiene acceso a credenciales. Cupos por espacio de trabajo. Requiere FARO_YOUTUBE_CLIENT_ID, FARO_YOUTUBE_CLIENT_SECRET y FARO_TOKEN_KEY (base64 de 32 bytes) solo en entorno privado de Function. Callback exacto: https://br-damp-scene-bbnr2g7d-farosocialapi.compute.c-15.us-east-1.aws.neon.tech/oauth/youtube/callback. Crear aplicación Google Cloud, activar YouTube Data API y configurar OAuth, revisión y políticas oficiales antes de uso comercial. No reutilizar Google compartido de Neon Auth. Sin credenciales el botón permanece deshabilitado. Pendientes renovación y revocación, reconciliación de autorizaciones no persistidas, limpieza de intentos, comprobación de sesión vigente y límites de tráfico, publicación y pruebas integrales. Facebook, Instagram y TikTok no implementados todavía.
