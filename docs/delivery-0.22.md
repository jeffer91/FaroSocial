# Adaptadores Instagram y TikTok 0.22
Instagram: validar identidad página/cuenta profesional, crear contenedor JPG o Reel MP4 con URL temporal, consultar estado y publicar solo FINISHED con intención registrada. PUBLISHED sin ID se trata como confirmación sin ID, nunca repetir. TikTok Direct Post: verificar open_id, consulta creator_info reciente, privacidad seleccionada, interacción y divulgación comercial/IA explícitas, duración validada; PULL_FROM_URL para archivo alojado en servidor. Sin auditoría, solo SELF_ONLY; confirmar únicamente PUBLISH_COMPLETE. No confundir publish_id con post_id; los int64 no representables se omiten. URLs deben ser HTTPS, origen verificado exacto y ruta delivery-media, emitidas por servidor. No existe todavía emisión de URLs de descarga firmadas de FaroSocial ni dominio verificado, ni integración del trabajador, ni persistencia de referencias/estados pendientes. No se habilita envío. Requiere validación multimedia real, consentimiento y datos del proveedor en UI, custodia de tokens y recuperación, revisión de aplicaciones y pruebas finales. Referencias: https://developers.facebook.com/docs/instagram-platform/instagram-api-with-facebook-login/content-publishing/ ; https://developers.tiktok.com/docs/en/content-posting-api-reference-direct-post ; https://developers.tiktok.com/docs/en/content-sharing-guidelines ; https://developers.tiktok.com/docs/en/content-posting-api-reference-get-video-status .
