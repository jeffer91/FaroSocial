# FaroSocial 0.13: acceso Google de prueba

Pantalla de diagnóstico en el origen HTTPS aislado de la función de desarrollo, no el alojamiento comercial. Cliente oficial @neon/auth y proveedor Google compartido exclusivamente para desarrollo. No se utiliza localStorage de FaroSocial ni el origen compartido jeffer91.github.io. El SDK gestiona la sesión; el código no imprime credenciales ni guarda tokens en tablas de la aplicación. Las solicitudes consultan /v1/me con un JWT de la sesión. Una identidad válida sin cuenta interna habilitada debe recibir 403. No se crean automáticamente cuentas comerciales ni se conceden roles. El administrador debe comprobar el usuario real en Neon Auth antes de habilitar una cuenta beta. La interfaz principal sigue siendo demostración. No se habilitan pagos ni publicación real. Antes de producción: credenciales Google propias, sesión vigente/revocación, límites de tráfico, hosting comercial y pruebas completas.
